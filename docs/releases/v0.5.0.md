# Mantis 0.5.0 — Quick recording & file names / Grabación rápida y nombres

**macOS 15+ · Apple Silicon · build 10**

## English

- Start or stop from the menu bar or SketchyBar without opening the library, even when Mantis was closed. First-time setup and errors still allow opening the app for review. Update notices no longer take over the recording click; busy clicks do not open the library.
- After a successful recording, a small Mantis window lets you edit the suggested file name. Audio is already saved before it appears. **Keep name**, Escape, or closing the window preserves the automatic name.
- Disable **Settings → General → When recording ends → Ask for a file name** to save directly, without the window. This option is on by default; automatic transcription remains off by default.
- Saving a new name renames the real audio and matching TXT, checks conflicts, and never replaces another file. Automatic transcription starts after the naming decision and uses the final path. Imports and failed recordings do not open the naming window.
- Dock icon now has transparent outer padding for a balanced visible size. The mantis artwork and website logo are unchanged.
- Includes multichannel input preservation and cancellable preparation fixes first delivered in the Sonoma compatibility channel.

## Español

- Inicia o detén desde la barra de menús o SketchyBar sin abrir la biblioteca, incluso si Mantis estaba cerrada. La bienvenida y los errores permiten abrir la app para revisar. Los avisos de actualización ya no reemplazan el clic para grabar; los clics durante procesamiento no abren la biblioteca.
- Después de grabar correctamente, una ventana pequeña de Mantis permite editar el nombre propuesto. El audio ya está guardado antes de mostrarla. **Mantener nombre**, Escape o cerrar conserva el nombre automático.
- Desactiva **Ajustes → General → Al terminar de grabar → Preguntar por el nombre del archivo** para guardar directamente sin ventana. Esta opción está activada por defecto; la transcripción automática sigue desactivada por defecto.
- Guardar otro nombre renombra el audio real y su TXT, revisa conflictos y nunca reemplaza otro archivo. La transcripción automática empieza después de decidir el nombre y usa la ruta definitiva. Importaciones y grabaciones fallidas no abren esta ventana.
- Icono del Dock con margen transparente para equilibrar su tamaño visible. No cambia la mantis ni el logo del sitio.
- Incluye las correcciones de selección multicanal y preparación cancelable entregadas primero en el canal de compatibilidad Sonoma.

## Install / Instalar

Download **Mantis-0.5.0.dmg**, quit Mantis completely, drag the app to Applications, replace the old copy, eject, and reopen. General should show **0.5.0**. Existing recordings, models and preferences are preserved. Existing SketchyBar installations that copied the plugin should update `scripts/sketchybar-recorder.sh` following the README; wrappers pointing to this repository already use it.

Descarga **Mantis-0.5.0.dmg**, sal completamente de Mantis, arrastra la app a Aplicaciones, reemplaza la copia anterior, expulsa y vuelve a abrir. General debe mostrar **0.5.0**. Se conservan grabaciones, modelos y preferencias. Si copiaste el plugin de SketchyBar, actualiza `scripts/sketchybar-recorder.sh` siguiendo el README; los wrappers que apuntan al repositorio ya lo usan.

For macOS 14, choose the **separate Sonoma test release**, not this installer. Para macOS 14, elige la **versión Sonoma de prueba separada**, no este instalador.

## Validation & limitations / Validación y límites

135 Swift tests per edition and 12 widget tests pass. Synthetic tests cover filename validation, conflict protection, rollback, saved-before-prompt flow, dismissal, disabled prompts and deferred transcription. EN/ES views were rendered offscreen. No real microphone/screen capture or permission resets are performed by these tests; real devices, permissions, long sessions and Sonoma remain manual validation tasks.

Ad hoc signed, **not notarized by Apple**. Updating may require macOS to authorize audio again; permissions are never reset automatically. Never disable Gatekeeper globally. Firma ad hoc, **sin notarización de Apple**. Una actualización puede requerir autorizar audio nuevamente; los permisos no se restablecen automáticamente. Nunca desactives Gatekeeper globalmente.
