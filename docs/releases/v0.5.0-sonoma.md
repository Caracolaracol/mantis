# Mantis 0.5.0 Sonoma — macOS 14 test edition / edición de prueba

**macOS 14+ · Apple Silicon · build 10 · separate prerelease**

This edition includes the same quick-recording, optional post-recording file-name window, and Dock icon improvements described in [Mantis 0.5.0](https://github.com/Caracolaracol/mantis/releases/tag/v0.5.0). It retains the native AVAudioEngine microphone path, multichannel selection fixes, cancellable preparation with stage messages and bounded ScreenCaptureKit waits from 0.4.2 Sonoma. Its update channel only offers tags ending in `-sonoma`.

Esta edición incluye las mismas mejoras de grabación rápida, ventana opcional para nombrar el archivo al terminar e icono del Dock descritas en [Mantis 0.5.0](https://github.com/Caracolaracol/mantis/releases/tag/v0.5.0). Conserva la ruta de micrófono AVAudioEngine, correcciones multicanal, preparación cancelable con etapas y esperas acotadas de ScreenCaptureKit de 0.4.2 Sonoma. Su canal de avisos solo ofrece etiquetas terminadas en `-sonoma`.

Download **Mantis-0.5.0-macOS14.dmg**. Quit any running copy, drag the app to Applications, replace the previous copy, eject, and reopen. Existing recordings/models/preferences remain. Do not run standard and Sonoma editions together. To suppress the new naming window, turn off **Settings → General → Ask for a file name**.

Descarga **Mantis-0.5.0-macOS14.dmg**. Sal de cualquier copia abierta, arrastra la app a Aplicaciones, reemplaza la anterior, expulsa y vuelve a abrir. Se conservan grabaciones, modelos y preferencias. No ejecutes ambas ediciones a la vez. Para omitir la nueva ventana de nombre, desactiva **Ajustes → General → Preguntar por el nombre del archivo**.

**Still a test edition: real Sonoma recording remains unverified.** 135 Swift tests pass for this build path on a macOS 15 host, using synthetic audio and mocked capture calls. They do not certify real Sonoma permissions, devices, synchronization or long sessions. Test computer-only, microphone-only, then combined; report exact macOS version, input device and stage/error if it fails. Do not rely on this as the only copy of an important recording.

**Sigue siendo de prueba: falta validar grabaciones reales en Sonoma.** Las 135 pruebas Swift se ejecutan para esta ruta en un Mac con macOS 15, con audio sintético y llamadas simuladas. No certifican permisos, dispositivos, sincronización ni sesiones largas en Sonoma. Prueba solo computador, solo micrófono y después ambos; envía versión exacta de macOS, dispositivo y etapa/error si falla. No la uses como única copia de una grabación importante.

Ad hoc signed, **not notarized by Apple**. No permissions are reset automatically. Never disable Gatekeeper globally. Firma ad hoc, **sin notarización de Apple**; no se restablecen permisos automáticamente. Nunca desactives Gatekeeper globalmente.
