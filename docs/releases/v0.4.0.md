# Mantis 0.4.0 — Update notices / Avisos de versiones

## English

- **Check for updates…** is available in the Mantis menu, menu-bar menu, and **Settings → General**.
- Optional automatic checks are **off by default**. Enable them in General to check GitHub at launch and while idle, at most once every 24 hours. Failed automatic attempts also count toward this limit; manual checks can be retried.
- New stable releases show a non-modal notice with **Release notes**, **Download update…**, **Later**, and **Skip this version**. The first two links open the official GitHub Release page; DMG download and installation remain manual.
- A menu-bar arrow indicates a pending notice while idle. Clicking opens Mantis rather than starting a recording; right-click still provides recording options.
- Checks are blocked during recording, transcription, model downloads, and permission operations. Notices wait until Mantis is idle. Nothing is installed automatically.
- GitHub receives a metadata request and your IP address, never recordings or transcripts. Requests use HTTPS without cookies or credentials, with size/time limits and trusted release links.

**Upgrading from 0.3.0:** install 0.4.0 manually once, then optionally enable automatic checks for future releases. Your existing recordings, model selection, and language preferences are not migrated or replaced.

## Español

- **Buscar actualizaciones…** está disponible en el menú Mantis, el menú de la barra y **Ajustes → General**.
- La revisión automática está **apagada por defecto**. Actívala en General para consultar GitHub al abrir y durante el reposo, como máximo una vez cada 24 horas. Los intentos automáticos fallidos también cuentan; la búsqueda manual permite reintentar.
- El aviso de una Release estable incluye **Ver novedades**, **Descargar actualización…**, **Más tarde** y **Omitir esta versión**. Los dos primeros enlaces abren la página oficial de la Release; descarga e instalación del DMG siguen siendo manuales.
- Una flecha en la barra indica un aviso pendiente cuando la app está en reposo. Pulsarla abre Mantis, no empieza a grabar; el clic derecho mantiene las opciones de grabación.
- Durante grabaciones, transcripciones, descargas de modelos u operaciones de permisos, se bloquean las búsquedas y se oculta el aviso hasta volver al reposo. No se instala nada automáticamente.
- GitHub recibe una consulta de metadatos y tu dirección IP, nunca grabaciones ni textos. HTTPS sin cookies ni credenciales, con límites de tamaño/tiempo y enlaces oficiales.

**Desde 0.3.0:** instala 0.4.0 manualmente una vez y, si quieres, activa la revisión automática para futuras versiones. No se migran ni reemplazan tus grabaciones, selección de modelo o preferencias de idioma.

## Install / Instalar

Requires **macOS 15+ and Apple Silicon**. Quit Mantis, open the DMG, drag it to **Applications**, eject the disk, and open the installed copy. Verify the attached SHA-256 checksum.

Requiere **macOS 15+ y Apple Silicon**. Sal de Mantis, abre el DMG, arrastra la app a **Applications / Aplicaciones**, expulsa el disco y abre la copia instalada. Verifica el checksum SHA-256 adjunto.

**Ad hoc signed; not notarized by Apple.** Updating can require renewed system-audio authorization. Only if needed, use **Settings → Privacy → Reset audio permission…**, then quit, reopen, and authorize in macOS. No permissions are reset automatically. Never disable Gatekeeper globally.

**Firma ad hoc, sin notarización de Apple.** Actualizar puede requerir renovar el permiso de audio. Solo si hace falta, usa **Ajustes → Privacidad → Restablecer permiso de audio…**, sal, vuelve a abrir y autoriza en macOS. No se restablecen permisos automáticamente. Nunca desactives Gatekeeper globalmente.
