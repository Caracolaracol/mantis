# Mantis 0.4.1 Sonoma — compatibility test release / versión de prueba

## English

Separate **macOS 14 Sonoma+ / Apple Silicon** edition. The standard Mantis 0.4.0 release for macOS 15+ remains unchanged and stays the latest stable release.

- System/application audio uses ScreenCaptureKit; microphone audio uses a separate AVAudioEngine input, aligned through host timestamps. Selected input devices and channels remain available.
- Sonoma-compatible launch/window restoration behavior avoids macOS-15-only SwiftUI APIs.
- Update notices use a separate Sonoma channel; they never offer the standard macOS-15-only download. Automatic checks remain off by default.
- English/Spanish, local transcription, library, manual update downloads, and the existing privacy controls are preserved.

Download **Mantis-0.4.1-macOS14.dmg**, quit any running copy, drag Mantis to Applications, eject the disk, and open the installed app. Verify the attached SHA-256 file. Choose one edition; do not run both at once. The bundle identifier and library locations are preserved.

**Test release:** compiled for macOS 14 and checked with synthetic capture and the Sonoma fallback forced on macOS 15. Actual permissions, capture devices, microphone/system synchronization, startup, and long sessions still need validation on a real Sonoma Mac. Do not use it as the only copy of an important recording.

## Español

Edición separada para **macOS 14 Sonoma o posterior / Apple Silicon**. La edición estándar Mantis 0.4.0 para macOS 15+ no se modifica y sigue siendo la última versión estable.

- Audio del computador o aplicación con ScreenCaptureKit; micrófono separado con AVAudioEngine, alineado mediante marcas de tiempo del reloj del sistema. Conserva selección de entradas y canales.
- Inicio y restauración de ventanas compatibles con Sonoma, sin APIs exclusivas de macOS 15.
- Canal propio de avisos: nunca ofrece el instalador estándar exclusivo de macOS 15. Revisión automática apagada por defecto.
- Se mantienen inglés/español, transcripción local, biblioteca, descarga manual de actualizaciones y controles de privacidad.

Descarga **Mantis-0.4.1-macOS14.dmg**, sal de cualquier copia abierta, arrastra Mantis a Aplicaciones, expulsa el disco y abre la app instalada. Verifica el archivo SHA-256 adjunto. Elige una edición; no ejecutes ambas a la vez. Se conservan identificador y ubicaciones de la biblioteca.

**Versión de prueba:** compilada para macOS 14 y revisada con captura sintética y la ruta Sonoma forzada en macOS 15. Falta validar permisos, dispositivos, sincronización de micrófono/sistema, inicio y sesiones largas en un Mac con Sonoma real. No la uses como única copia de una grabación importante.

## Automated checks / Pruebas automatizadas

108 Swift tests pass for each build variant, including a decoded-signal synchronization test and update-channel isolation. The DMG executable and bundle both declare macOS 14.0 as their minimum; it includes English/Spanish resources and the arm64 engine. These checks do not replace running it on macOS 14 itself.

108 pruebas Swift pasan por variante, incluida sincronización mediante señal decodificada y aislamiento del canal de avisos. El ejecutable y el bundle declaran mínimo macOS 14.0 e incluyen recursos inglés/español y motor arm64. Estas verificaciones no sustituyen ejecutarla en macOS 14 real.

## Signing / Firma

Ad hoc signed, **not notarized by Apple**. An update can require renewed audio authorization; no permissions are reset automatically. Never disable Gatekeeper globally.

Firma ad hoc, **sin notarización de Apple**. Una actualización puede requerir renovar la autorización de audio; no se restablecen permisos automáticamente. Nunca desactives Gatekeeper globalmente.
