# Mantis 0.4.2 Sonoma — recording preparation fixes / correcciones de preparación

Separate **macOS 14+ / Apple Silicon test edition**. Standard Mantis 0.4.0 for macOS 15+ remains unchanged and stays the latest stable release.

## English

- Both input channels may remain selected. Reapplying the same device no longer resets the selection; the last selected channel cannot accidentally be unchecked.
- Microphone capture uses the device’s native input format, rather than its potentially stale output/graph format. Empty selections and unavailable channels now have distinct errors, including requested and actual channel counts.
- Preparation shows whether it is checking permissions, finding audio sources, or starting computer/microphone audio. **Cancel preparation** is available in the window and menu bar.
- ScreenCaptureKit source and start callbacks have 15-second deadlines. A microphone permission decision is not timed out, but preparation can be canceled while waiting.
- Canceled or timed-out attempts never adopt a late callback as a fresh recording. Late successful starts request cleanup. If macOS does not confirm a stop, Mantis preserves available temporary audio, warns you to quit, and blocks a new capture until restart.
- Whole-computer capture avoids the empty excluding-windows filter documented to cause missing callbacks on older ScreenCaptureKit versions. This is a compatibility hardening change, not confirmation of the exact cause on the reported Sonoma Mac.

## Español

- Se pueden mantener ambos canales seleccionados. Reaplicar la misma entrada ya no reinicia la selección; no se puede desmarcar accidentalmente el último canal.
- El micrófono usa el formato nativo de entrada, no un formato de salida/grafo potencialmente anterior. Selección vacía y canales no disponibles tienen errores distintos, con canales solicitados y cantidad real.
- La preparación muestra si está verificando permisos, buscando fuentes o iniciando audio del computador/micrófono. **Cancelar preparación** está disponible en ventana y barra de menús.
- Las esperas de fuentes e inicio de ScreenCaptureKit tienen límite de 15 segundos. No se impone ese límite a la decisión del usuario en un permiso de micrófono; se puede cancelar la preparación mientras espera.
- Un inicio cancelado o vencido no adopta un callback tardío como una nueva grabación. Los inicios tardíos solicitan detener su stream. Si macOS no confirma una detención, Mantis conserva el temporal disponible, avisa que hay que salir e impide iniciar otra captura hasta reiniciar la app.
- La captura del computador evita el filtro de ventanas vacío documentado como problemático en ScreenCaptureKit antiguo. Es una mejora preventiva de compatibilidad, no confirmación de la causa exacta en el equipo con Sonoma reportado.

## Install / Instalar

Download **Mantis-0.4.2-macOS14.dmg**, quit any running copy of Mantis, drag the app to Applications, eject the disk, and reopen. Check General shows **0.4.2**. Do not run standard and Sonoma editions at once. Existing library and model locations are unchanged.

Descarga **Mantis-0.4.2-macOS14.dmg**, sal completamente de cualquier copia de Mantis, arrastra la app a Aplicaciones, expulsa el disco y vuelve a abrir. General debe mostrar **0.4.2**. No ejecutes las ediciones estándar y Sonoma a la vez. No cambian las ubicaciones de biblioteca ni modelos.

Ad hoc signed, **not notarized by Apple**. No permissions are reset automatically. Never disable Gatekeeper globally. Firma ad hoc, **sin notarización de Apple**; no se restablecen permisos automáticamente. Nunca desactives Gatekeeper globalmente.

## Validation / Validación

119 Swift tests pass for each build variant, including simulated missing callbacks, cancellation, late completion cleanup, actual model busy-state recovery, stereo selection and synthetic audio synchronization. No real microphone or screen capture was started by these tests.
