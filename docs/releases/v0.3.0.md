# Mantis 0.3.0

## English and Spanish

- English is the default for both the app and website.
- Choose a language during setup or in **Settings → General → Language**.
- Existing recording titles, transcripts, filenames, and audio are not translated or migrated.
- The SketchyBar plugin follows the language published by Mantis.

## Website

- New headline: **What you hear, Mantis records.**
- EN/ES switcher for the home page, documentation, and MIT license.
- Larger bare mantis-head mark and a smaller portfolio snail.
- An occasional mantis-arm strike behind the content, leaving a fading afterimage. Motion can be paused and respects reduced-motion preferences.

## Install

Requires **macOS 15+ and Apple Silicon**. Quit Mantis, open the DMG, drag the app to **Applications**, eject the disk, and open the installed copy.

This build is **ad hoc signed and not notarized by Apple**. Updating may require renewing system audio permission. Use **Settings → Privacy → Reset audio permission…**, then quit, reopen, and authorize again. No permissions are reset automatically.

The release includes the engine and MIT license, but no model weights, recordings, or preferences. Verify the DMG with the attached `.sha256` file.

## Validation

87 Swift tests, 12 Python widget tests, and 7 website tests pass. Native English/Spanish previews use fictional data. Six website pages were checked at mobile, tablet, and desktop widths, including the attack, afterimage, fade, pause, and reduced-motion behavior.

Real meetings, hardware, macOS login, and external upload receivers still require manual validation. Source code is MIT; engine, dependencies, and models retain their own licenses.
